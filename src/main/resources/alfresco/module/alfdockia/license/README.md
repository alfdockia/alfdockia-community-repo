# Clave publica de licencias AlfDokia

En builds oficiales, coloca aqui la clave publica:

```text
alfdokia-license-public.pem
```

AlfDokia usa esa clave para verificar licencias firmadas. No guardes nunca la
clave privada en este directorio, en el repositorio, en imagenes Docker ni en
artefactos entregados a clientes.
